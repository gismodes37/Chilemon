ChileMon

A modern dashboard for AllStarLink ASL3 nodes, inspired by the Supermon concept, but built on a more organized, secure, modular, and installable foundation. The current v0.4.0 release already includes browser-based PTT, WebRTC/IAX2 bridge, hardened security, installation map, and Windows Companion, with ongoing improvements landing on the main branch.

Features

ChileMon is no longer just an idea or a technical base: the current release delivers a first functional and usable version on real nodes.

Automatic Installer

Guided installation with validations, structure creation, wrapper setup, local configuration, and a final access summary.

Per-Node Configuration

Each installation generates its own config/local.php based on the real node environment.

Environment Auto-Detection

Detects node hostname and AMI parameters from the real ASL/Asterisk installation when available.

Login + Session

Controlled access, protected endpoints, and a secure foundation for dashboard administration.

Standard SQLite

No MySQL or MariaDB. Installation stays simple, portable, and easy to maintain on the node.

Secure Wrapper

Controlled use of Asterisk commands through chilemon-rpt and tightly scoped sudo rules.

ASL & EchoLink

Functional connection and disconnection from the dashboard for AllStarLink and EchoLink nodes (via prefix 3 + 7 digits).

Per-User Favorites

Quick access to frequent nodes with alias and custom description per authenticated user.

Recent Activity

Basic event logging to support node operation and monitoring.

Push-to-Talk Web

Browser-based PTT via WebRTC Audio Bridge + IAX2. Radio communication without physical equipment.

Security

ChileMon is built to grow on a secure, controlled, and predictable foundation inside an ASL3 node.

Authentication and Session

  • CSRF protection in forms.
  • Centralized session handling with consistent login/logout.
  • Dynamic BASE_PATH / BASE_URL for sub-path deployments on real nodes.
  • Protected endpoints under session/authorization control.

Secure Operation on the Node

  • Secure wrapper for Asterisk rpt commands.
  • Scoped sudoers for www-data.
  • Non-versioned local configuration in config/local.php.
  • SQLite / PDO validation before application initialization.
The database, logs, backups, and local configuration are generated on the node. They should not be uploaded to the repository or treated as part of the source code.

Installation

ChileMon is installed on the node and publishes its interface under /chilemon. The current installer detects hostname and AMI parameters from the real environment when possible.

Requirements and tested environments

  • Tested systems: Raspberry Pi 3B+ with ASL3 and Proxmox virtual machine with Debian 13 + ASL3
  • Apache + PHP 8.x
  • PHP extensions: PDO, pdo_sqlite, and sqlite3
  • Git installed on the node
The recommended installation creates per-node local configuration, initializes SQLite, and leaves the web access working under /chilemon.

Recommended workflow

# Clone stable version and install
$ curl -fsSL https://raw.githubusercontent.com/gismodes37/Chilemon/main/install/bootstrap.sh -o /tmp/bootstrap.sh && sudo bash /tmp/bootstrap.sh
The installer leaves a final summary with the access URL, local node, detected AMI user, WebRTC bridge status, and relevant installation data.

Option: Debian 13 VM + ASL3

For a clean dedicated system. Create a VM with VirtualBox or Proxmox, install Debian 13 + ASL3, then ChileMon.

# Clone and install
$ curl -fsSL https://raw.githubusercontent.com/gismodes37/Chilemon/main/install/bootstrap.sh -o /tmp/bootstrap.sh && sudo bash /tmp/bootstrap.sh
The installer auto-detects NEW vs UPDATE mode. The WebRTC bridge (browser PTT) is installed as part of the process.
Keep a single official Apache path pointing to /opt/chilemon/public to avoid conflicts on the node.

Architecture

Current Components

  • UI: public/views/*
  • Auth: login/logout + session + CSRF + roles
  • API: public/api/*
  • DB: SQLite in data/chilemon.sqlite
  • Schema: install/sql/schema.sql
  • Config: config/app.php + config/local.php
  • Installer: install/install_chilemon.sh (13 steps)
  • WebRTC Bridge: app/Services/WebRTCBridge/ (Python, IAX2 server)
  • Asterisk Wrapper: /usr/local/bin/chilemon-rpt
  • Tests: tests/ (PHPUnit scaffold)

Progress, stages, and roadmap

ChileMon is developed in controlled stages: operational stability on real ASL3 nodes first, then audio/security, then production hardening. The main branch is the official install source and where validated improvements land.

What already works

  • Operational dashboard, login/session, SQLite, and automatic installer.
  • Connect/disconnect nodes, favorites, recent activity, RX/TX, and EchoLink.
  • WebRTC PTT from browser with ASL3-compatible IAX2 bridge.
  • Security: CSRF, rate limiting, roles, node whitelist, no hardcoded credentials.
  • Admin panel, health check, installation map, and Windows Companion.

Where we are now

  • On main: improved RX/TX visualizer (higher sensitivity, 48 bars, intensity color).
  • Improving Companion UX: diagnostics, reconnect flow, and status clarity.
  • ES/EN installation docs aligned for tutorial recording and onboarding.
  • Real-node validation before closing the next release.

Where we are heading

  • Reliable remote PTT outside local networks (TURN/STUN, HTTPS/WSS).
  • Multi-user sessions and better bridge operational control.
  • CI, production testing, and hardening for a solid 1.0 release.
  • Keep installation simple: main always installable.
